# PDF in motion – Downloads

Hier liegen die fertigen Versionen von **PDF in motion** (Windows 10/11, 64 Bit).
Der Programmcode ist nicht öffentlich.

**Installieren:** Unter [Releases](../../releases/latest) die Datei
`PDF-in-motion-<Version>-Setup.exe` herunterladen und doppelklicken.

**Updates:** Installierte Versionen fragen beim Start hier nach einer neueren
Version und bieten das Update an (abschaltbar im Menü unter „Updates“). Jede
Datei wird vor dem Start mit ihrer Prüfsumme (`SHA256SUMS.txt`) verglichen.
